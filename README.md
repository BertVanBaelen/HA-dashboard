# Thuis Dashboard – Home Assistant App repository

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FBertVanBaelen%2FHA-dashboard)

Mobiel, mooi en per gebruiker instelbaar dashboard voor Home Assistant, met tabs:
Home · Klimaat · Verlichting · Media · Auto · Agenda & Lijsten · Personen · Systeem · Grafieken.

- Svelte 5 frontend, Node.js backend (HA WebSocket via Supervisor)
- Ingress → werkt in de zijbalk en in de Companion app
- Thema's: auto/licht/donker × blauw/groen/roze

Zie [thuis_dashboard/DOCS.md](thuis_dashboard/DOCS.md) voor installatie en de benodigde scripts.
